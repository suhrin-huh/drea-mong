# 개발용 Mock API

`npm run dev`에서는 백엔드 없이 공통 Axios adapter가 모든 업무별 API 모듈에 목 응답을 제공한다. 페이지별 샘플이나 서버 실패 시 자동 fallback은 사용하지 않는다. 미구현 요청은 501로 실패한다.

실제 서버를 연결할 때 `frontend/.env.local`에 다음을 설정하고 개발 서버를 재시작한다.

```dotenv
VITE_API_MOCK=false
VITE_API_BASE_URL=http://localhost:8080
```

- 목 모드는 Vite 개발 서버에서만 활성화된다. 프로덕션 빌드에서는 설정과 무관하게 비활성화되고 목 adapter는 번들에서 제외된다.
- 초기 데이터는 현재 월의 꿈 15개, 공유 꿈, 댓글, 스트리밍 방과 고정 관리자 사용자다. 관리자 역할은 방 관리 화면 확인을 위한 데모 설정이다.
- 꿈 작성·임시 저장·수정·삭제, 공유, 댓글 생성·삭제·좋아요, 닉네임 변경, 방 생성·삭제는 같은 메모리 저장소를 변경한다. 화면 이동 후 재조회에도 반영된다. 새로고침하면 초기화된다.
- 월별 꿈과 통계는 선택한 월로 필터링한다. 광장 커서 페이지 처리를 제공한다. 통계 키워드와 AI 이미지·해몽은 예시이며 실제 분석 결과가 아니다.
- 목 모드에서는 토큰 없이 화면을 확인하고 로그인 버튼은 데모 홈으로 이동한다. 실제 토큰을 생성·덮어쓰거나 서버로 전송하지 않는다. 로그아웃은 로그인 화면으로 이동하지만 목 모드의 데모 접근은 계속 가능하다.
- 실시간 서버 연결은 생략하고 채팅 입력은 현재 방 화면에서만 표시한다. 다른 사용자·탭과 동기화되지 않는다. YouTube 영상은 외부 플레이어를 그대로 사용한다.
- Firebase 초기화·알림 권한 요청·실제 푸시는 실행하지 않는다. 설정 토글은 데모 화면 상태만 바꾼다.
- 브라우저 음성 입력 등 클라이언트 기능은 기존 동작을 유지한다. 목 데이터는 실제 인증·권한·AI·푸시·다중 사용자 동작을 검증하지 않는다.
